Privacy Policy

Clothing Listing and Pricing Assistant

Last updated: October 20, 2026

1. Purpose

This application is a personal tool used to research clothing prices, prepare product listings, and manage listings for the owner's eBay seller account.

2. Data Access

The application may access eBay listing information, marketplace pricing information, and authorized seller account information through eBay APIs.

3. Data Storage

eBay API data is processed temporarily and is not persistently stored. The application maintains locally created clothing descriptions, photographs, pricing recommendations, and manually entered sales information.

4. Data Sharing

The application does not sell personal information or share eBay account information for advertising. Third-party service providers, including AI services, may process information required to operate the tool.

5. Data Security

API credentials are protected and application access is restricted to the owner.

6. Data Retention

eBay API data is processed transiently and discarded. Locally created inventory records may be retained or deleted by the application owner.

7. Contact

For questions about this privacy policy, contact: lemonvogue@yahoo.com
